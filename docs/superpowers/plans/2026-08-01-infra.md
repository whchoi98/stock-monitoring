# Infra (Docker + CDK) Implementation Plan — Plan 3/3

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CloudFront → Prefix SG → ALB → ECS Fargate + DynamoDB로 stock-monitoring을 ap-northeast-2에 배포한다.

**Architecture:** CDK Python 단일 스택. 기존 `cc-on-bedrock-vpc`(vpc-0dfa5610180dfa628)를 lookup으로 참조만. 멀티스테이지 Dockerfile을 `DockerImageAsset`으로 빌드·푸시. 오리진 이중 방어: ALB SG는 CloudFront prefix list(pl-22a6434b)만 허용 + ALB 리스너 규칙이 `X-Origin-Verify` 헤더 검증.

**Tech Stack:** Docker, AWS CDK v2 (Python), boto3

**Spec:** `docs/superpowers/specs/2026-08-01-stock-monitoring-design.md` §3
**전제:** Plan 1·2 완료 (backend 테스트 GREEN, `make build`로 backend/static 생성 가능)

## Global Constraints

- 리전 `ap-northeast-2`, 계정 `061525506239`, VPC `vpc-0dfa5610180dfa628` — **네트워크 리소스(VPC/서브넷/NATGW/IGW) 신규 생성 절대 금지**
- 모든 리소스 이름 프리픽스 `stock-monitoring` (공유 VPC 충돌 방지)
- ALB SG 인바운드는 prefix list `pl-22a6434b`의 80 포트 **단 1규칙** (prefix list가 ~55 슬롯 소비 — 전용 SG 필수)
- Fargate: Public Subnet 배치 금지 — ALB만 public(`subnet-08486a1e618b1991e`, `subnet-0c161777c4031c320`), 태스크는 private(`subnet-07b1e65682847dce9`, `subnet-095297380cd45e1eb`)
- Task Role 최소 권한: `bedrock:InvokeModel`(전 리소스) + DynamoDB(GetItem/PutItem/BatchGetItem/BatchWriteItem/Query, 해당 테이블 ARN 한정)
- CloudFront 오리진 프로토콜 HTTP_ONLY (ALB 무인증서), Viewer는 redirect-to-https
- `cdk.json`의 context에 VPC lookup 결과가 pin됨 — `cdk.context.json` 커밋 필수

- [ ] **Step 2: 스택 구현** — `stock_monitoring_stack.py` 구성 요소 (순서대로):
```python
# 1) VPC 참조 (생성 금지)
vpc = ec2.Vpc.from_lookup(self, "Vpc", vpc_id="vpc-0dfa5610180dfa628")

# 2) DynamoDB 캐시 테이블
table = dynamodb.Table(self, "CacheTable",
    table_name="stock-monitoring-cache",
    partition_key=dynamodb.Attribute(name="pk", type=dynamodb.AttributeType.STRING),
    billing_mode=dynamodb.BillingMode.PAY_PER_REQUEST,
    time_to_live_attribute="ttl",
    removal_policy=cdk.RemovalPolicy.DESTROY)

# 3) 오리진 검증 시크릿 (난수 32자, 헤더값으로 사용)
origin_secret = secretsmanager.Secret(self, "OriginVerifySecret",
    secret_name="stock-monitoring/origin-verify",
    generate_secret_string=secretsmanager.SecretStringGenerator(
        exclude_punctuation=True, password_length=32))
header_value = origin_secret.secret_value.unsafe_unwrap()  # synth-time 참조

# 4) ECS 클러스터 + 이미지
cluster = ecs.Cluster(self, "Cluster", cluster_name="stock-monitoring", vpc=vpc)
image = ecr_assets.DockerImageAsset(self, "Image", directory="..")  # 루트 Dockerfile

# 5) 태스크 정의 (0.5 vCPU / 1GB) + 권한 + 로그
task_def = ecs.FargateTaskDefinition(self, "TaskDef", cpu=512, memory_limit_mib=1024)
task_def.add_container("app",
    image=ecs.ContainerImage.from_docker_image_asset(image),
    port_mappings=[ecs.PortMapping(container_port=8000)],
    environment={"CACHE_TABLE": table.table_name, "BEDROCK_REGION": "ap-northeast-2"},
    logging=ecs.LogDrivers.aws_logs(stream_prefix="stock-monitoring",
        log_retention=logs.RetentionDays.TWO_WEEKS))
table.grant_read_write_data(task_def.task_role)
task_def.task_role.add_to_principal_policy(iam.PolicyStatement(
    actions=["bedrock:InvokeModel"], resources=["*"]))

# 6) Fargate 서비스 — private 서브넷 명시
service = ecs.FargateService(self, "Service", cluster=cluster,
    task_definition=task_def, desired_count=1,
    vpc_subnets=ec2.SubnetSelection(subnets=[
        ec2.Subnet.from_subnet_id(self, "Priv1", "subnet-07b1e65682847dce9"),
        ec2.Subnet.from_subnet_id(self, "Priv2", "subnet-095297380cd45e1eb")]),
    min_healthy_percent=100, max_healthy_percent=200)

# 7) ALB — public 서브넷 + 전용 SG(prefix list만)
alb_sg = ec2.SecurityGroup(self, "AlbSg", vpc=vpc, allow_all_outbound=True,
    description="stock-monitoring ALB - CloudFront prefix list only")
alb_sg.add_ingress_rule(ec2.Peer.prefix_list("pl-22a6434b"), ec2.Port.tcp(80))
alb = elbv2.ApplicationLoadBalancer(self, "Alb", vpc=vpc, internet_facing=True,
    security_group=alb_sg,
    vpc_subnets=ec2.SubnetSelection(subnets=[
        ec2.Subnet.from_subnet_id(self, "Pub1", "subnet-08486a1e618b1991e"),
        ec2.Subnet.from_subnet_id(self, "Pub2", "subnet-0c161777c4031c320")]))

# 8) 리스너: 기본 403, X-Origin-Verify 일치 시에만 forward
listener = alb.add_listener("Http", port=80,
    default_action=elbv2.ListenerAction.fixed_response(403, content_type="text/plain",
        message_body="Forbidden"))
tg = elbv2.ApplicationTargetGroup(self, "Tg", vpc=vpc, port=8000,
    protocol=elbv2.ApplicationProtocol.HTTP, targets=[service],
    health_check=elbv2.HealthCheck(path="/api/health", healthy_http_codes="200"))
listener.add_action("VerifiedForward", priority=1,
    conditions=[elbv2.ListenerCondition.http_header("X-Origin-Verify", [header_value])],
    action=elbv2.ListenerAction.forward([tg]))

# 9) CloudFront — /api/* 무캐시, /assets/* 장기캐시(불변 해시 파일명), 기본 index 캐시 짧게
origin = origins.HttpOrigin(alb.load_balancer_dns_name,
    protocol_policy=cloudfront.OriginProtocolPolicy.HTTP_ONLY,
    custom_headers={"X-Origin-Verify": header_value})
dist = cloudfront.Distribution(self, "Dist",
    default_behavior=cloudfront.BehaviorOptions(origin=origin,
        viewer_protocol_policy=cloudfront.ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
        cache_policy=cloudfront.CachePolicy.CACHING_DISABLED,
        allowed_methods=cloudfront.AllowedMethods.ALLOW_ALL,
        compress=True),
    additional_behaviors={"/assets/*": cloudfront.BehaviorOptions(origin=origin,
        viewer_protocol_policy=cloudfront.ViewerProtocolPolicy.REDIRECT_TO_HTTPS,
        cache_policy=cloudfront.CachePolicy.CACHING_OPTIMIZED, compress=True)})

# 10) 알람 2개 + Outputs
cloudwatch.Alarm(self, "Alb5xx",
    metric=alb.metrics.http_code_elb(elbv2.HttpCodeElb.ELB_5XX_COUNT,
        period=cdk.Duration.minutes(5)),
    threshold=10, evaluation_periods=1)
cloudwatch.Alarm(self, "TaskCount",
    metric=service.metric("RunningTaskCount", statistic="Minimum",
        period=cdk.Duration.minutes(5)),
    threshold=1, comparison_operator=cloudwatch.ComparisonOperator.LESS_THAN_THRESHOLD,
    evaluation_periods=2)
cdk.CfnOutput(self, "CloudFrontURL", value=f"https://{dist.distribution_domain_name}")
cdk.CfnOutput(self, "AlbDNS", value=alb.load_balancer_dns_name)
cdk.CfnOutput(self, "CacheTableName", value=table.table_name)
```
주의: `from_subnet_id` 서브넷은 route table 정보가 없어 CDK 경고가 나오지만 배치에는 문제 없음. `unsafe_unwrap()`은 헤더값이 CloudFormation 템플릿에 resolve되는 것을 허용하는 명시적 선택(리스너 규칙 조건은 시크릿 동적 참조 불가) — 시크릿은 로테이션 필요 시 스택 재배포로 갱신.

## Self-Review 결과 반영 사항

- 스펙 §3 "Secrets Manager에 시크릿 저장 + 양쪽 참조" — ALB 리스너 헤더 조건이 동적 참조를 지원하지 않아 synth-time resolve(`unsafe_unwrap`) 사용을 명시. 시크릿 원본은 Secrets Manager에 존재하므로 스펙 의도(하드코딩 금지, 로테이션 가능) 충족
- ALB 액세스 로그는 스펙에 없어 미포함 (YAGNI). 컨테이너 로그 2주 보존은 I2 §5에 반영
- Fargate 아웃바운드: 서비스 기본 SG(전체 아웃바운드 허용) 사용 — Yahoo/RSS는 NAT, ECR/로그/Bedrock/DynamoDB는 기존 VPC 엔드포인트가 자동 경유

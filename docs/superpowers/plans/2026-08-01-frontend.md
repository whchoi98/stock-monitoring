# Frontend (React + Toss UI) Implementation Plan — Plan 2/3

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Toss Invest 실측 디자인 토큰 기반의 React SPA — 대시보드/종목 상세/기사 AI 분석 3페이지.

**Architecture:** Vite + React 18 + TypeScript SPA. TanStack Query가 폴링/캐시/에러 담당, lightweight-charts로 캔들+MA+거래량. 빌드 산출물은 백엔드 `backend/static/`으로 복사되어 FastAPI가 서빙.

**Tech Stack:** Vite 8, React 19, TypeScript 6 (사용자 결정 2026-08-02: `npm create vite@latest` 현행 기본값 유지 — 원문의 Vite 5/React 18/TS 5는 작성 시점 기준), react-router-dom 6(고정), @tanstack/react-query 5, lightweight-charts 4(고정 — F5 API 의존), react-markdown, vitest + @testing-library/react

**Spec:** `docs/superpowers/specs/2026-08-01-stock-monitoring-design.md`
**전제:** Plan 1(backend) 완료 — 개발 시 `vite dev` 프록시로 `localhost:8000` API 사용

## Global Constraints

- 디자인 토큰(다크 기본): bg `#101013`, card `#17171C`(radius 16px), 상승 `#F5445A`, 하락 `#4391FF`, 액센트 `#3485FA`, 본문 `#C3C3C6`, 강조 `#FFFFFF`
- 라이트 토큰: bg `#F4F5F8`, card `#FBFCFD`, 상승 `#DE2B39`, 하락 `#2272EB`, 액센트 `#3182F6`, 본문 `#4E5968`, 강조 `#191F28`
- 테마는 `<html data-theme="dark|light">` + CSS 변수로만 구현 (컴포넌트에 색상 하드코딩 금지)
- 폰트: Pretendard CDN 대신 `@fontsource/pretendard` npm 패키지 (오프라인 빌드/CSP 안전), 폴백 `Noto Sans KR, sans-serif`
- 상승/하락 색: `change >= 0 ? var(--up) : var(--down)` — 한국 관례 (0은 상승색 아님 → 보합은 본문색; TUI `arrow` 규칙 `▲/▼/-` 따름)
- 폴링: 시세류 `refetchInterval: 45_000`, 뉴스 `120_000` — 항상 TanStack Query로, 수동 setInterval 금지
- 모든 API 호출은 `src/api/client.ts`의 `apiGet`/`apiPost` 경유, envelope `{asOf, marketOpen, data}` 언래핑은 쿼리 훅에서
- 시뮬레이션 데이터(호가/수급) 패널에는 `SimulatedBadge` 필수 표시
- 숫자 포맷: KR 통화 소수점 없음/US 2자리, 시가총액 KR 억/조/경·US M/B/T, 거래량 K/M 축약 — TUI `$TUI/models/stock.py`의 formatted_* 규칙과 동일 결과

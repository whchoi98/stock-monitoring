# ADR-001: 터미널 디자인 언어 채택과 앰버 액센트 / Adopt a terminal design language with an amber accent

- 날짜 / Date: 2026-09-06
- 상태 / Status: Accepted
- 관련 스펙 / Spec: `docs/superpowers/specs/2026-09-06-terminal-ui-redesign-design.md`

## 맥락 / Context

초기 UI는 Toss Invest를 참조한 카드형(16px 라운드, 넉넉한 여백, 1280px 중앙 정렬) 대시보드였다.
사용자는 `img/`의 두 참조 이미지(Seoul Terminal 스타일 한국어 터미널, Bloomberg Terminal)를 제시하며
"실제 상용 증권앱 스타일 수준"으로의 개편을 요구했다. 두 이미지는 밀도 높은 패널 그리드, 대문자 소형
패널 헤더, 고정 마켓 스트립, 워치리스트 레일, 하단 상태 바, 고정폭 숫자라는 디자인 언어를 공유한다.

참조 이미지는 **서구식 등락색(상승 초록/하락 빨강)**과 **파랑 또는 오렌지 액센트**를 쓴다. 이 프로젝트는
한국 관례(상승 빨강/하락 파랑)를 정확성 규칙으로 고정하고 있다(`CLAUDE.md`).

## 결정 / Decision

1. **터미널 디자인 언어를 채택한다**: 뷰포트를 가득 채우는 워크스페이스 그리드, 1px 테두리 + 6px 라운드 패널,
   eyebrow(대문자 소형 라벨) + 제목 + 액션의 패널 헤더, 상단 마켓 스트립, 하단 상태 바, 숫자·심볼·시각은
   고정폭 서체(JetBrains Mono).
2. **등락색은 한국 관례를 유지한다**(상승 빨강 / 하락 파랑 / 보합 본문색). 참조 이미지의 초록/빨강은 채택하지 않는다.
3. **액센트는 앰버(`--accent: #F2A93B` 다크 / `#B8720A` 라이트)**로 바꾼다. 선택·포커스·주요 버튼에 쓴다.
4. **상태 색 `--ok`(초록)를 추가**하되 등락에는 절대 쓰지 않는다 — 연결/장중 표시 전용.
5. 지수는 별도 카드가 아니라 **모든 화면의 마켓 스트립**에서 보여준다.

## 근거 / Rationale

- 하락색이 파랑이므로 **파란 액센트는 "선택됨"과 "하락"이 같은 색축에 놓여** 워치리스트·표에서 혼동을 만든다.
  앰버는 빨강/파랑 어느 쪽과도 겹치지 않는 고채도 축이고, Bloomberg가 수십 년 쓴 터미널 관례라 사용자에게
  "전문 도구"로 읽힌다.
- 초록 `--ok`는 상태 점(장중·연결)에만 쓴다. 등락에 초록이 섞이면 한국 관례가 무너지므로 토큰 이름부터 분리했다.
- 지수를 스트립으로 올리면 대시보드 첫 행이 비어 시장요약·섹터·뉴스를 한 화면에 담을 수 있고, 종목 화면에서도
  지수가 항상 보인다(터미널의 기본 기대).

## 결과 / Consequences

- `--card` 토큰과 `Card` 컴포넌트가 사라지고 `--panel`/`Panel`이 대체한다. `PriceChart`가 캔버스에 넘기는
  토큰명도 함께 바뀐다.
- 라이트 테마는 "종이 위의 터미널"로 유지한다 — 밀도는 같고 대비만 반전.
- JetBrains Mono(라틴 서브셋, 400/700)가 번들에 추가된다(수십 KB). 한글 숫자 조합에서 폴백은 `ui-monospace`.
- 참조 이미지의 주문/포트폴리오/옵션 패널처럼 **데이터가 없는 패널은 만들지 않는다**. 빈 패널은 신뢰를 깎는다.
